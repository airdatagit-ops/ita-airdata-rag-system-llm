Sobre o Sistema

O que é o AirData RAG System?

O AirData RAG System é uma plataforma de inteligência artificial especializada em regulamentações da aviação civil brasileira. Utilizando tecnologia RAG (Retrieval-Augmented Generation), o sistema combina busca semântica avançada com modelos de linguagem para fornecer respostas precisas, contextualizadas e verificáveis sobre normas da ANAC.

Desenvolvido pelo Instituto Tecnológico de Aeronáutica (ITA) como parte do Projeto AirData, a plataforma oferece uma interface conversacional intuitiva onde profissionais da aviação podem obter informações regulatórias de forma rápida e confiável, com sistema de avaliação de qualidade integrado.

Como Funciona?

O sistema utiliza uma arquitetura RAG (Retrieval-Augmented Generation) distribuída:

  1. Interface Web: Aplicação FastAPI com chat em tempo real, sistema de avaliação por estrelas e histórico persistente de conversas.
  2. API RAG: Servidor especializado que processa consultas, realiza busca vetorial no Qdrant e gera respostas usando modelos LLM via Ollama.
  3. Base de Conhecimento: Documentos da ANAC processados e indexados como embeddings vetoriais com metadados temporais e regulatórios.

Quando você faz uma pergunta, o sistema converte sua consulta em um vetor semântico, busca os trechos mais relevantes dos documentos oficiais da ANAC, e utiliza um modelo de linguagem para sintetizar uma resposta coerente. Você pode então avaliar a qualidade da resposta em 5 dimensões diferentes.

Recursos Principais

  • 🤖
    Chat Conversacional: Interface de bate-papo com IA especializada em aviação civil, com streaming de respostas em tempo real.
  • 📋
    Avaliação de Qualidade: Sistema de 5 estrelas para avaliar precisão, completude, clareza, citações e relevância de cada resposta.
  • 📚
    Fontes ANAC Verificáveis: Todas as respostas baseadas em documentos oficiais da ANAC, com citações precisas e scores de relevância.
  • ⚡
    Busca Vetorial Qdrant Sistema de busca semântica de alta performance para encontrar conteúdo relevante instantaneamente.
  • 🔍
    Busca sem IA: Ferramenta de busca vetorial direta para explorar documentos similares sem processamento de linguagem.
  • 📊
    Histórico Completo: Todas as conversas salvas com títulos automáticos, avaliações persistentes e métricas de uso detalhadas.
