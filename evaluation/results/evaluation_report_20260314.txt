4. OBSERVAÇÕES IMPORTANTES
--------------------------------------------------------------------------------

  4.1 Mismatch de IDs no Golden Set
  ----------------------------------
  Muitos "misses" encontram o documento correto mas com ID de chunk
  diferente do esperado. Exemplos:

    Q022: esperava ICA-7-58        → retornou ICA-7-58-art2-0       (mesmo doc!)
    Q023: esperava ICA-35-13       → retornou ICA-35-13-art3-0      (mesmo doc!)
    Q031: esperava ICA-100-40-art1 → retornou ICA-100-40-art3-3     (mesmo doc!)
    Q038: esperava ICA-81-4        → retornou ICA-81-4-art3-6       (mesmo doc!)
    Q042: esperava ICA-63-15-art1  → retornou ICA-63-15-art3-6      (mesmo doc!)
    Q057: esperava ICA-37-924      → retornou ICA-37-924-art3-6     (mesmo doc!)

  Se a avaliação usasse match por prefixo de regulation_id (nível de
  documento em vez de chunk), o hit rate seria significativamente maior
  em todos os 3 modos.

  RECOMENDAÇÃO: Atualizar o golden set para refletir os IDs de chunk
  atuais, ou implementar avaliação com match por prefixo.

  4.2 Degradação vs. Baseline Anterior
  --------------------------------------
  A baseline anterior (Hit Rate 41.8%) foi avaliada ANTES das mudanças de:
  - TextCleaner (remoção de headers, footers, page numbers, ROT-3)
  - QualityValidator (rejeição de documentos garbage/low quality)
  - Reestruturação de chunks/IDs

  A degradação NÃO indica que a limpeza piorou a qualidade real.
  Indica que o golden set precisa ser recalibrado para os novos IDs.
